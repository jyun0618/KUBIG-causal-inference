# 인과추론 스터디 (KUBIG)

26-2 KUBIG Advanced Study - 인과추론

## 소개

최근 추천 시스템, 정책 평가, A/B 테스트, 마케팅 분석 등 다양한 분야에서 단순 예측을 넘어 원인(Causality)을 분석하는 방법이 중요해지고 있습니다. 본 스터디는 인과추론(Causal Inference)의 핵심 개념과 주요 방법론을 학습하고, 이를 데이터 분석 및 머신러닝 문제에 적용해보는 것을 목표로 하며, 『실무로 통하는 인과추론 with 파이썬』 교재를 기반으로 인과추론에 관한 전반적인 내용을 학습합니다.

## 교재

『실무로 통하는 인과추론 with 파이썬』 (마테우스 파쿠레, 한빛미디어)

## 디렉토리 구조

```
week_n/          # 주차별 폴더
└── chapter_nn/  # 해당 주차에서 다루는 장 폴더
```

챕터가 없는 주차(1, 7, 8, 9주차)는 빈 폴더로 유지됩니다.

## 폴더 · 파일명 규칙

| 대상 | 규칙 | 예시 |
|---|---|---|
| 주차 폴더 | `week_n` (n = 1~9) | `week_2` |
| 챕터 폴더 | `chapter_nn` (두 자리 숫자) | `chapter01`, `chapter12` |
| 실습 코드 파일 | `{이름}_실습.ipynb` | `승민_실습.ipynb` |

- 발제 자료는 레포에 올리지 않고 슬랙에 공유합니다.
- 팀 구분이 필요한 경우 파일명에 팀을 추가로 표기해도 됩니다 (예: `1팀_승민_실습.ipynb`).
